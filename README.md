## Fonctionnalités
-structure des propriétés, initialisation des propriété
-structure des joueurs
-test des premières fonctions

## Compilation
Utilisez le Makefile inclus pour compiler le projet en tapant,
-Pour compiler le code principal :
    make
-Pour compiler les tests :
    make test
-Pour clean :
    make clean

## Lancement
Ensuite, pour 
-Lancer le code principal, tapez:
    ./insapoly
-Lancer les tests :
    ./unit_tests
